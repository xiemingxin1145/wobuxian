## 1. 服装外观·套装（扩展 COSTUMES）P0 — 文件 `cos36.js`

**设计**：时装拆为 4 部位（冠/衣/佩/履）+ 原整套作"套装皮"。部位单件无属性（保持外观本色），**集齐套装 2/4 件**激活小额套装效果，避免付费数值化。

**数据**：
```js
COS36 = { xiake:{ parts:['guan','yi','pei','lv'], set2:{luck:0.03}, set4:{spd:0.05,  pass:'酒葫芦：战斗回血2%/回合'} }, ... }
G.cos36 = { own:{'xiake.guan':1}, wear:{guan:null,yi:null,pei:null,lv:null}, dye:{} }   // 老档缺省 → 由 meta.cos 推导
```
- 老档兼容：`Game.meta.cos[id]=1` 视为该套 4 件全部拥有（不吞已有收藏）；`G.costume` 映射为 4 部位全穿。
- 套装效果上限：set2 ≤ 3%，set4 ≤ 6%（单项），同时只生效 1 套 set4 + 1 套 set2。

**来源/消耗（对照现有经济）**：
| 来源 | 产出 | 备注 |
|---|---|---|
| 抽卡 cos 池（已有） | 整套 | 不变 |
| 世界BOSS（worldboss33）击杀 | 部位碎片 ×1，10 碎片=1 部位 | 每日上限 3 片 |
| 江湖声望（jianghu34）商店 | 部位 800 灵石 + 声望 | 约 0.4 枚洗髓丹价格 |
| 染色 | 染料 150 灵石/次 | 纯 sink，无属性 |
| 重复部位 | 分解为 3 碎片 | |

**UI**：角色面板「时装」页签增加 4 部位格 + 套装进度条（2/4 亮灯）+ 染色按钮。
**验收**：
- A1.1 老档持有 xifu → 载入后 own 中 xifu 4 件全在，外观与旧版一致。
- A1.2 穿 xiake 2 件：幸运 +3%（显示值 = 基础×1.03，误差≤1）；4 件额外速度 +5%。
- A1.3 穿两套各 4 件不可能；两套 2+2 时仅取效果更高的一套 set2 + 另一套 set2 = 合计 ≤6%。
- A1.4 碎片每日第 4 片不掉落。

## 3. 灵根深化（扩展 LINGGEN，不替换）P0 — 文件 `lg36.js`

**现状**：灵根只影响修为倍率 mult，el 仅展示。**深化**为三维影响 + 多条洗灵根路线。

**元素亲和**：`el` 中每个元素给对应属性技能伤害 +X%，X = 24% / 元素数（单灵根 +24%，双 +12%/个，五行 +4.8%/个，none 0）。异灵根（雷/冰）额外 +6%。
**突破修正**：`brk' = brk + Δ`，Δ：none +0.05（"废柴心定"补偿，喜剧向）/ wu 0 / si 0 / san 0 / shuang -0.02 / tian -0.04 / lei,bing -0.05（天才遭天妒）；封顶 0.95，下限 0.1。
**纯度** `G.lg36.pur`（0–100，老档默认 50）：修为倍率最终 = mult × (0.9 + pur/500)，即 0.9–1.1。纯度来源：打坐静修 +1/日（上限 70）、灵根丹 +5、心魔幻境小成 +3。

**洗灵根**（保留原 xsd）：
| 方式 | 消耗 | 效果 |
|---|---|---|
| 洗髓丹 xsd（已有） | 2000 灵石 | 向上一档，纯度 -20 |
| 逆脉洗根 | 灵石 5000 + 寿元 10% | 重随（可能变差），纯度不变 |
| 定向淬根 | 天材地宝×3 + 8000 | 增/删 1 个元素（档位按元素数重算） |
| 轮回 | — | 已有 rollLinggen，不变 |

**存档兼容**：`G.lg` 不动；新增 `G.lg36={pur:50, extraEl:[]}`；无 lg36 时以 LINGGEN 原值运行。
**验收**：
- A3.1 老档 san 灵根载入：cultMult 前后比值 = (0.9+50/500)=1.00，体感无变化。
- A3.2 tian 金灵根，金系技能伤害 ×1.24（非异灵根，无额外 6%）；lei 雷技 ×1.30。
- A3.3 lei 灵根元婴→化神突破显示 0.42-0.05=37%。
- A3.4 逆脉洗根 1000 次蒙特卡洛，结果分布与 LINGGEN 权重偏差 <2 个百分点。

## 4. 收徒扩展·多徒弟门下（扩展 legacy26）P1 — 文件 `dis36.js`

**现状**：只有 1 个"衣钵弟子"。**扩展**为：衣钵弟子位保留（仍唯一，用于传承）+ 新增"记名弟子" 最多 N 名，N = max(0, tier-1)（筑基 1 / 金丹 2 / 元婴 3 / 化神 4 / 渡劫 5）。

**弟子数据**：
```js
G.dis36 = [{ id, n, lg:'san', pur:40, lvl:1, xp:0, apt:0.8, loy:60, state:'idle'|'study'|'out', npc:null }]
```
- 灵根按 LINGGEN 权重随机（主角 shuang 及以上时，弟子高档权重 ×1.3）；apt 资质 0.6–1.4。
- 成长：每游戏年 xp += 20 × mult(弟子灵根) × apt × (1 + 0.1×师父教学次数本年)，升级需 50×lvl。
- **教学**：消耗主角当日行动 1 次，弟子 xp +30，主角修为 +1%need（教学相长），每年上限 6 次。
- **派遣**：派往地图采集/历练，每游戏年结算一次（G.year 变化时结算，同 pet35）。年收益 = 40 × 弟子等级 × 地图档位 灵石（tier0 按 0.5），弟子等级≥5 时 ×1.5；10% 概率带回碎晶/碎片；失败率 max(5%, 30%−lvl×2%)，失败 loy-10。派遣槽：灵宠与弟子**共享**，总上限 = 1 + floor(大境界/2)，最多 4（同 pet35），避免双倍挂机产出；若 pet35 不存在，弟子单独按同一公式计槽。
- **L.rel 联动**：从可结交 NPC 收徒需 aff≥60 且 L.rel≥20（比衣钵 80 低）；弟子 loy≥80 时其原 NPC 的 L.rel +1/年；逐出门墙 L.rel -30。
- **继承**：衣钵空缺时可从记名弟子中"立嗣"（lvl≥5），转为 G.apprentice 并沿用 legacy26 传承逻辑。
- 收徒费用（sink）：拜师礼反向——主角需出"束脩补贴"300×N 灵石/年，交不上 loy-15（契合欠债主题）。

**验收**：
- A4.1 金丹主角最多 2 名记名弟子 + 1 衣钵，第 3 名记名按钮置灰。
- A4.2 san 弟子 apt 1.0、无教学：1 年 xp=20；教学 6 次后 xp=20×1.6+180=212。
- A4.3 lvl3 弟子派往 tier3 东海仙岛 → 灵石 360。
- A4.4 老档有 G.apprentice → 衣钵位不变、dis36=[]。
- A4.5 大境界4 时灵宠+弟子总派遣上限 3，第4个被拒。
- A4.6 3级弟子派往档位2地图一年得 240 灵石。
