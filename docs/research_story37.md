## 1. NPC 关系网与自发事件（3.7.0，`npc37.js`）P0

**数据**
```js
G.npc37 = { v:1,
  rel:{ 'jh_jianke|jh_mozi': -45 },   // NPC↔NPC，键按字典序拼接，−100..100
  tie:{ 'jh_yangui|jh_jianke':'dl' }, // 关系标签 dl道侣/sf师徒(前师后徒)/ch仇
  st:{ jh_mozi:{dead:0, born:0} },    // 陨落/新人
  yc:{ yr:0, n:0, per:{}, map:{} },   // 本年计数：全局 n、每人 per[id]、地图冷却 map[mapId]=绝对月
  ev:{}                              // 已触发一次性事件 id
}
```
参与者：6 位 `jh_*` + 11 位 `Talk.prefs` 熟人（共 17 人）；初始 NPC↔NPC 关系按宗门：同宗 +20、`G.sectRel` 敌对宗 −20、其余 0。年度衰减（鬼谷式）：|rel|>60 的每年向 0 移 5。

**事件表（年结算时掷，`JH34` 年末钩子之后）**

| 事件 | 条件 | 基础概率/年·对 | 效果 |
|---|---|---|---|
| 结仇 | 两人同图或敌对宗，rel<0 | 8% | rel −30，≤−60 → tie=ch |
| 结亲(道侣) | 双方未婚，rel≥60 | 5% | tie=dl，各 +10 |
| 拜师 | 境界差≥2，rel≥30 | 6% | tie=sf，徒境界 +资质加成 |
| 突破 | 复用 JH34 修炼结果 | — | 只发新闻 |
| 陨落 | 境界寿元到期 or 仇杀败方 | 仇杀 3%/仇对 | st.dead=1；玩家 `L.rel` 与其 ≥40 → 弹"吊唁"小场景 |
| 夺宝 | 寻宝/war 性格，奇遇链节点空闲 | 4% | 抢先完成某奇遇节点（见 §4 失败态） |

**频率上限（开放世界 bot 要求）**
- 每 NPC 每年：最多 **2** 条自发事件（`yc.per[id]≤2`），其中最多 1 条为 结仇/陨落。
- 全局每年：最多 **6** 条入新闻，其中最多 **2** 条 toast（本图/本宗/与玩家 rel≥40 者相关才 toast）。新闻写 `G.jh34.feed`（沿用 FEED_MAX 40，`k:'npc37'`）。
- 每年产生新闻目标 **3–6 条**（低于 3 时用"闲话"补到 3）。
- 地图遭遇冷却：同一地图的路遇小场景 **≥6 个游戏月**一次（`yc.map[mapId]`），每年全图合计 ≤4 次。
- 仇家不重复：沿用 life34 规则——同一仇家一年内只上门一次；npc37 产生的 NPC 仇人若已是本年 `L.pending.npc`，本年不再生成路遇；`Stage3.huntBlocksFoe` 为真时本年不发仇杀类路遇。

**路遇小场景（地图上按日程行走的 NPC）**
触发：玩家与 `NPCS[id].roam` 同图且距离≤2 格 + 地图冷却到期 + 本人本年额度未满；按 `Life34.rel` 与 `Life34.yr()` 选场景：
- rel≤−40：挑衅（战/赔礼 灵石 = 100×(境界+1)，赔礼 rel+15）
- −40<rel<40：搭话/打听（读 feed 最近 2 条，本年首次 rel+2）
- rel≥40：同行（赠礼一件 or 带路至奇遇链节点）；rel≥80 且年≥ `born+20`：提"结为道侣"（链接 §3）
- 特殊：merchant（钱多多）在 market 遇见且 `G.debt>0` → 进入奇遇链 #1 节点；xianguan（记账童子）在 heaven → 链 #2。

**内容量**：6 类事件 × 每类 4 条新闻模板 = 24 条；路遇 3 档 × 5 句 = 15 句；吊唁 3 句。合计约 42 行。
**验收**：A1.1 模拟 100 年，任一 NPC 单年事件 ≤2，全局单年新闻 ≤6 且 ≥3；A1.2 同图 6 个月内不出第二次路遇；A1.3 本年已有仇家上门者不再路遇挑衅；A1.4 rel 永远在 −100..100；A1.5 陨落 NPC 从地图移除，任务给予者（merchant/xianguan/mentor 等主线 NPC）**免死**。
**存档兼容**：`G.npc37` 缺省惰性初始化，不改 `G.v`；老档首年从宗门推导初始 rel。

## 2. 对话选项与后果（3.7.1，`talk37.js`）P0

**数据**：`G.mem37 = { f:{ 'ali_lie':{yr:12} }, due:[{at:15, id:'ali_lie_out'}], dx:0 }`；`dx` 道心 −50..50；善恶用现有 `G.karma`。
**规则**
- 包裹 `Talk` 的 NPC 菜单追加「⚐ 抉择」项（每 NPC 每年最多 1 次），每个抉择 2–3 选项，效果只取：`G.aff ±5~20`（同步 rel×0.5 由 life34 已有逻辑完成，不再重复加）、`dx ±3~10`、`G.karma ±5~15`、物品/灵石。
- 延迟后果：选项可写 memory flag + `due`（1–5 年后），年结算出队触发卡片；每年最多 2 个 due 生效，余者顺延。
- 道心：dx≤−30 时心魔幻境（v33 第 7 项）难度 +1；dx≥30 突破成功率 +3 个百分点（并入 95% 封顶）。
**内容量**：首批 12 位 NPC × 2 抉择 = 24 个抉择、约 60 选项，其中 10 个带延迟后果（≥10 张后果卡）。
**验收**：A2.1 选"撒谎"后 3 年整弹出揭穿卡；A2.2 同 NPC 同年第二次无「⚐ 抉择」；A2.3 karma/dx 夹取；A2.4 读档 due 不丢、不重复触发（`ev` 去重）。
**兼容**：老档 `G.mem37` 缺省空；flag 命名前缀 `m37_` 不与 `G.flags` 冲突。

## 3. 家族传承与人物关系（3.7.2，`fam37.js`）P1

**数据**
```js
G.fam37 = { v:1, spouse:'sumei', since:30,
  kids:[{ id:'k1', name:'王小二', lg:'shuang', mom:'sumei', born:35, realm:0, alive:1, sect:null }],
  gen:1, tree:[{gen:0,name,lg,end:'feisheng'}] }
```
- 道侣：`G.aff[id]≥100` 且 `L.rel[id]≥60`、双方未有 npc37 `tie=dl` → 结道侣，写 `G.partner`（兼容 legacy26）。
- 子嗣：结侣后每 10 年 25% 得一子，上限 4 人；`G.heir` 始终指向嫡传（kids 中灵根最高者）保持 legacy26 兼容。
- 灵根遗传（接 research_v36 灵根档位 none→wu→si→san→shuang→tian/lei/bing）：取父母较高档 −1 为基线，60% 基线、25% 升一档、15% 降一档；双方均天/异灵根时 5% 出异灵根。NPC 道侣灵根按其资质映射（资质≥1.2→shuang）。
- 代际继承：玩家陨落或飞升时，若有存活子嗣/衣钵弟子 → 选择"以后人续玩"：继承 `G.surname`、30% 灵石、1 门功法（同 legacy26 apprenticeTechs 规则），债务按天道规则 **50% 父债子还**（梗 + 接天道讨债主线）。
**内容量**：结侣 3 段 × 6 可婚 NPC = 18 段；子嗣出生/成年/拜师 9 条模板；继承过场 4 张卡。
**验收**：A3.1 父 tian+母 san 抽 1000 次，基线 shuang 约 60%±4；A3.2 老档有 `G.heir` → 迁移为 kids[0]；A3.3 继承后 `G.debt` = 原值×0.5（取整）；A3.4 家谱面板显示 ≥3 代。
**兼容**：`G.fam37` 缺省由 `G.partner/G.heir` 推导；`Game.meta.daotong` 不改。

## 5. 自由路线（3.7.4，`route37.js`）P1

`G.route37 = { id:'sanxiu', pts:0, since:yr }`，开局或任意时刻在「更多→道途」切换（每 10 年一次）。主线照常可做，不做也能结局。
| 路线 | 进入条件 | 核心循环 | 新结局 |
|---|---|---|---|
| 散修 | 无宗门 `!G.sect` | 奇遇链加权 ×1.5、自由接江湖任务 | **逍遥游**：元婴+完成 4 条奇遇链+债清 |
| 魔修 | karma≤−50 | 夺宝/仇杀可主动发起，修为 +15% | **魔君**：击败 3 名正道 NPC + 天魔宗 sectRel≥60 |
| 宗门掌门 | `G.sectLeader` | 宗门大比/宗门战/收徒 | 并入现有 `wanxian` |
| 凡人商贾 | realm=0 且年龄≥30 主动放弃修炼 | 坊市倒卖（market25）、放贷给 jh_tieguo 等 | **富甲一方**：灵石≥100 万并**反向收购讨债司**（天道讨债的喜剧反转） |

所有新结局在 end30 列表追加，`where` 指向对应 NPC；与天道讨债结局并列，不覆盖。
**内容量**：4 新结局 × 结局卡 1 + 前置提示 2 = 12 张卡；路线切换文案 5 条。
**验收**：A5.1 不推主线可达"富甲一方"（dev 面板给钱验证）；A5.2 魔修切回需 karma≥0；A5.3 老档默认 `route37=null` 行为不变。

## 6. 开放世界 bot 可接的钩子

- `NPC37.onMeet(id, mapId)`：游走 NPC 与玩家同图距离≤2 时由 bigmap34/world28 调用，内部做 §1 冷却与 rel 判定，返回 `null|scene`。
- `NPC37.schedule(id, month)`：返回 NPC 本月目标图（读 JH34 游历结果），供开放世界寻路。
- `NPC37.emit(kind, a, b)`：开放世界内两 NPC 相遇（如同图打斗）可上报，计入年度额度。
- 事件总线 `window.Story37 = {on(evt,fn)}`：`'npc:dead'|'npc:wed'|'chain:fail'|'route:end'`。
- 约束：钩子只读 `Life34.rel` / `Life34.yr()`，写入只走 `Life34.rel()` 和 `G.npc37`；场景对话以「⚑」开头避免挂机代选。
