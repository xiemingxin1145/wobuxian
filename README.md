# 我不仙 · 修仙人生模拟器

> 从凡人开始，欠天道一个飞升。

一款 **2.5D 等角视角 · Q 版国风** 的修仙人生模拟器（安卓 APK / 网页单文件均可玩）。
你将从一个桃花村的婴儿开始，抽天赋、摸灵根，一年一年长大，拜入宗门、闯秘境、斗妖怪、渡天劫，
从 **凡人 → 练气 → 筑基 → 金丹 → 元婴 → 化神 → 渡劫 → 飞升**。
寿元耗尽或被雷劈死后，带着“轮回点”重新投胎，越轮回越强。
落魄剑仙（出自 MV《我不仙》）会以“师父”的身份登场——主要是来借钱的。

所有美术（等角地图、Q 版人物、怪物、特效、图标）均为 Canvas 程序化实时绘制，所有音效与古风背景乐均为 WebAudio 程序化合成，**无任何外部/版权素材**，完全离线运行。

## 怎么玩

| 操作 | 说明 |
| --- | --- |
| **投胎** | 从候选天赋中选 3 个（可刷新），点“摸骨”测灵根，分配先天属性（体魄/悟性/气运/魅力/家境） |
| **行动** | 底部四个按钮，每点一次就过一年（筑基后“闭关”一次过多年），之后可能触发随机奇遇（带选项的事件卡） |
| **突破** | 修为满且达到“圆满”时，“突破”按钮会发光。金丹起需要渡 **天劫**，失败可能身死道消 |
| **地图** | 桃花村（种地打工读书）、青云宗（修炼×1.5、宗门任务、大比）、云来坊市（摆摊、丹药铺、奇遇）、万妖秘境（斩妖历练、寻宝） |
| **斗法** | 在等角地图上自动进行，飞剑/符箓/妖火互射，伤害飘字、暴击、震屏。**点击屏幕加速** |
| **行囊** | 查看/服用丹药（回春丹、延寿丹、培元丹……），查看天赋 |
| **轮回殿** | 死后获得轮回点，永久提升：属性点、天赋候选、初始灵石、寿元、灵根保底、刷新次数 |
| **往世录** | 记录你的每一世：名字、灵根、享年、境界、死因 |

终极目标：渡过十二道天劫，打败 **讨尾款的天道**，白日飞升！

小贴士：
- 没有功法的凡人只能“瞎练吐纳”，记得拜师（落魄剑仙）、进宗门或在旧书摊淘秘籍；
- 坊市的“筑基丹”能大幅提升练气→筑基的成功率，“替死符”能在渡劫失败时救命；
- 有【赊账剑诀】可以把灵石欠到负数——讨债鬼会戴着“一见还钱”的高帽上门。
- 进度自动保存在本地（localStorage），退出后可“继续此生”。安卓返回键 = 关闭弹窗 / 打开菜单。

## 文件结构

```
www/                 游戏源码（HTML5 Canvas + 原生 JS，无依赖）
  index.html, style.css
  js/render.js       2.5D 等角渲染器：浮空岛、瓦片、建筑/树木精灵、Q版小人、怪物、粒子、雷劫、飘字
  js/game.js         人生模拟逻辑：投胎、行动、事件、斗法、突破/天劫、死亡结算、轮回殿、存档
  js/data.js         境界、灵根、天赋、事件（≈45 个带选项的搞笑事件）、物品、轮回殿
  js/audio.js        WebAudio 程序化音效 + 五声音阶古筝风背景乐
android/             极简 Android WebView 外壳工程（Gradle / AGP 8.7，无 AndroidX 依赖）
dist/wobuxian.html   单文件可玩版（所有 JS/CSS 内联，手机浏览器直接打开即可玩）
wobuxian.apk         调试签名 APK（约 0.2 MB）
screenshots/         游戏截图
build.sh             一键构建脚本
test/                无头浏览器自动化测试（Playwright + Chrome）
```

## 构建

环境：JDK 17、Android SDK（platform android-35、build-tools 35.0.0）、Gradle 8.9、Python 3。

```bash
export JAVA_HOME=/path/to/jdk-17
export ANDROID_HOME=/path/to/android-sdk     # 或在 android/local.properties 里写 sdk.dir
./build.sh                                    # 生成 dist/wobuxian.html 和 wobuxian.apk
```

`build.sh` 做三件事：① 用 `tools/inline.py` 把网页内联成单文件；② 把 `www/` 拷进 `android/app/src/main/assets/www/`；
③ `gradle assembleDebug` 产出调试签名 APK 并复制到 `wobuxian.apk`。

本地网页调试：直接用浏览器打开 `www/index.html`（或 `dist/wobuxian.html`），用手机竖屏尺寸查看效果最佳。

## 安装

把 `wobuxian.apk` 发到安卓手机，点击安装（需允许“安装未知来源应用”）。最低 Android 7.0，竖屏全屏。

## 测试

```bash
pip install playwright
python3 test/play.py        # 走一遍完整流程并截图，输出 JS 错误与帧率
python3 test/bot.py 4       # 机器人自动玩 4 世，检验数值平衡
```
