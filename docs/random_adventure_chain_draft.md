# 随机奇遇链草稿（开放世界阶段 3）

> 目标：地图上随机刷点，玩家选择影响 NPC 态度、债务额度、下一世。
> 隔离：先做草稿，不接入正式任务栏，仅开发者入口或独立原型测试。

## 链结构（3 步）
1. **遇见**：随机 NPC（路人/流动者）向玩家求助（送信/还债/打怪）。
2. **选择**：
   - 帮忙：NPC 好感 +20，可能降债务。
   - 拒绝：NPC 态度 -15，可能记仇。
   - 赖账：债务 +10%，下一世承受部分。
3. **后果**：影响关系网，可触发追兵或报恩事件。

## 示例链 1：渡口船夫·过河欠条
1. 遇见渡口船夫，求玩家帮忙送信到邻图（或先付过河费）。
2. 选择：
   - 帮忙送信：船夫 rel +20，下次过河免费一次。
   - 拒绝：rel -15，船夫记仇，下次可能涨价。
   - 赖账（欠条不还）：债务 +8%，下一世可能被追。
3. 后果：若帮忙，触发报恩小事件（灵石）；若记仇，年度模拟可能刷寻仇来客。

**可测原型**：`www/prototypes/adventure_chain/index.html`（独立页面，选择即可看 rel/debt 变化与后果描述）。

## 示例链 2：守山弟子·后山禁地
1. 遇见守山弟子，说后山有禁地怪物乱窜，求帮忙清扫。
2. 选择：
   - 帮忙打怪：rel +25，可得小量贡献。
   - 拒绝：rel -10，弟子记下。
   - 赖账不应：债务 +5%（宗门记账）。
3. 后果：帮忙则后续可触发禁地宝箱事件；记仇则年度可能出现宗门执法来客。
