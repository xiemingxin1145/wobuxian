# 开放世界 / 混合战斗升级方案（v2.5+ 方向）

> 目标：在保持现有 2.5D 等距 + 人生模拟核心的前提下，往鬼谷八荒风格的开放感 + 即时/半即时战斗扩展，让游戏更爽、更有选择权重、减少“老套路”感。
> 当前基础：正式发布 v2.3.0；工作分支 openworld-wip。低模离线样例已完成签收；即时遭遇战独立原型已可玩；奇遇链草稿已有六条并带路径断言。

## 优先级与阶段

### 阶段 1：视觉与模型升级（最快见效）
- 从 Cube / Cylinder Extrude + Mirror + Loop Cut 做低模 Q 版人形底模（替代纯球体堆叠）。
- 本批明确做 3 个关键角色：主角男、主角女、剑仙；使用自建 Cube/Cylinder 挤出、Mirror 与 Loop Cut 形成的低模源模型，不采用 Quaternius/proto v2 替代本阶段路线。
- 渲染管线可复用现有 art/ 脚本，只改源模型。
- 目标：剪影更清晰，减少“鸡蛋”感。
- 预览为 Blender 独立场景，不接入 `www/`、精灵图集、正式地图或运行链；用贴近桃花村现有等距镜头/屏幕尺度的构图对比当前角色，检查身形比例、轮廓可读性，以及名牌/点击目标留白。清楚标注这是离线渲染对比，不是实机或运行中地图截图。
- 工具允许时，在独立预览中补充待机、移动和一个动作姿态；不为展示动画而接入游戏。

**当前：** art/prototypes/openworld_v25/ 三角色已完成并签收（离线资产）。另有运行时草稿 `www/js/lowpoly_box_chars.js`（2026-10-19）：Canvas 现画长方体 Q 版人（青衫剑修 / 讨债鬼差 / 主角女 / 剑仙，四向 + 待机/行走/挥砍/受击），预览页 `www/prototypes/lowpoly_box/`，只给即时战原型 `skin:'box'` 试用，不进正式加载链；单测 `test/lowpoly_box.js`。
**扩展样例（2026-10-25 ~ 10-28）：** `www/js/lowpoly_extra_chars.js` 已加路人甲、主角男、渡口船夫、药农、黑市商人、散修、宗门弟子、药贩、催债使者、**仙官·记账童子**（本步新增）。预览页已支持下拉切换与四向/动作预览。仍不接入正式加载链。

### 阶段 2：战斗混合化原型
- 地图探索保持等距自由走或走格子耗时间。
- 遭遇战 / 小怪战改为**即时或半即时**：玩家直接操控移动 + 普攻 + 技能 + 闪避，敌人放弹道/技能。
- 更轻量过渡：ATB（行动条到顶插队，可暂停选技能）。
- Boss 战和关键剧情战先保留回合制。
- 先做一个可玩的“遭遇战即时”原型（小地图或同地图切换）。

**灵根 × 武器技能（2026-10-19）：** 原型「技」按灵根元素变形（火锥形灼烧 / 水冰减速灵珠 / 金贯穿剑气 / 木定身藤 / 其他灵弹），剑扇伞分别修正伤害弹速 / 范围 / 冷却，多灵根可切换；灵根武器只读存档。

**当前：** www/prototypes/encounter/ 赤松坡试炼场已可玩（覆盖层打开）；www/js/battle_realtime_prototype.js（2026-10-19）已接游戏现有角色精灵（主角 `Game.playerSpr()`、敌人 `mon_slime`，八方向 + idle/walk/attack/hurt 动画），普攻为面向 ±60° 扇形命中判定 + 伤害飘字 + 受击闪白/击退，另有 Shift 闪避、Q 弹道、敌人弹道；自带覆盖层画布 + rAF 循环 + 触屏摇杆/攻技闪按钮，**只由开发者入口「即时战」按钮打开**（`RealtimeBattle.open`），不包 `Game.fight`、不改存档。正式小怪即时战由 main 的 `rt27.js` 承担，本原型只做手感实验。单测 `test/battle_rt_proto.js`、页面冒烟 `test/battle_rt_proto_page.py`。

（其余阶段 2 对照表、阶段 3 债务强化 #1-#9、life34 对接等详细内容保持不变，见之前提交。本步仅追加低模扩展记录。）
