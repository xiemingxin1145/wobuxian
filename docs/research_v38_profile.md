## 1. 现有代码事实（已核对 origin/main）

- 境界：`REALMS`（data.js）8 档：凡人0/练气1/筑基2/金丹3/元婴4/化神5/渡劫6/飞升7；小层 `STAGES = ['初期','中期','后期','圆满']`，`G.stage` 0–3。**没有「练气5层」这种东西**，所有门槛写成 `realm/stage`。
- 灵根：`LINGGEN`（none/wu/si/san/shuang/tian/lei/bing），玩家 `G.lg`；子嗣 `kid.lg`；道侣灵根 `FAM37.SP_LG`。
- 好感：`G.aff[id]`（0–150，talk.js 送礼上限 150）；关系：`Life34.st().rel[id]`（L.rel，−100..100，`FAM37.relOf(id)` 读取）；分档 ≤−40 仇 / ≥40 友（npc37）。
- 玩家命格：`MINGGE`（mingge33.js，`G.mingge` 数组）——**这是玩家命格**。本文的 NPC 命格是**另一张表 `NPC_MG38`**，id 以 `n_` 前缀，避免与 `MINGGE` 的 id 冲突。
- NPC 表：`NPCS`（data.js + content22/23 + maps25/26 + jianghu34 动态生成 `jh_*` + bigmap34）。送礼最爱 `Talk.prefs`。
- 善恶 `G.karma`；随机 `Game.roll(p, kind)`；效果串 `Game.apply('aff:id:n;karma+n;item:k:n;...')`。

## 2. 存档字段

```js
G.pf38 = {
  v: 1,
  seen: { [npcId]: { lg:1, mg:1, aff:1, sec:[0,1] } }, // 已解锁的隐藏项（永久，跨年保留；轮回清空）
  hid: { [npcId]: { lg:'lei', mg:'n_tiansha', taff:Δ } }, // 惰性生成的隐藏数据（首次打开面板时按 hash(npcId+G.name) 生成，固定不变）
  peek: { yr: 0, n: 0 },       // 本年神识窥探次数
  fail: { [npcId]: yr }        // 窥探被发现的年份（当年该 NPC 不可再窥）
};
```
- 命名 NPC（TEXT38A.fixed 中写死的）隐藏数据**固定**，不随机；`jh_*` 江湖人和路人按 hash 从池中取。
- 真实好感 `taff = G.aff[id] + Δ`，Δ 存 hid，范围 −40..+30。**显示好感仍为 G.aff**，真实好感只用于面板与少数事件判定（背叛/告白），不回写 G.aff。

## 3. 神识值与解锁门槛

`神识 SS = G.realm × 4 + G.stage`（凡人初期 0 … 渡劫圆满 27，飞升 28）。额外：玩家命格含 `wuxing` +2；法宝/道具临时加成见 v40。

| 隐藏项 | 神识门槛 | 道具替代 | 好感替代 |
|---|---|---|---|
| 基础（境界/性格/好感/关系） | 无，默认可见 | — | — |
| 隐藏灵根 | SS ≥ 6（筑基中期）且 目标大境界 ≤ 玩家 | `kuixin_jing` 窥灵镜（v40） | aff ≥ 80 对方主动告知 |
| 命格 | SS ≥ 10（金丹后期）且 目标大境界 ≤ 玩家 | `mingpan` 命盘残页 | aff ≥ 120 |
| 真实好感 | SS ≥ 13（元婴中期） | `tongxin_xiang` 同心香（单次，当年有效） | rel ≥ 60 且 aff ≥ 100（道侣自动可见） |
| 秘密① | SS ≥ 16（化神初期） | `mixin_zha` 密信 / 剧情道具 | aff ≥ 130 |
| 秘密② | SS ≥ 20（渡劫初期） | 专属剧情道具（见 v40） | aff = 150 且 rel ≥ 80 |

- 目标境界高于玩家：神识窥探直接失败（「对方神识如山，把你弹了回来」）。道具与好感途径不受此限。
- **神识窥探**：面板按钮「👁 以神识窥探」，每年 3 次（`peek.n`）。成功率 = clamp(0.55 + 0.05×(SS − 门槛) − 0.1×(目标realm − 玩家realm 为0时0), 0.2, 0.95)，走 `Game.roll(p,'peek')`（cheat luck 不吃，kind 不在白名单）。失败 30% 被发现：`aff:id:-8`、`L.rel −5`、记 `fail[id]=yr`，弹 TEXT38A.peek.caught。
- karma ≥ 30 的玩家窥探成功率 −10%（正道心虚），karma ≤ −30 被发现的惩罚翻倍。

## 5. 数值与效果

- 解锁「隐藏灵根」后：若是异灵根（lei/bing）或天灵根，可在 3.8.3 婚配时作为联姻加分项；记名弟子收徒时显示真实资质。
- 解锁「命格」后：命格效果**生效与否不依赖解锁**（一直生效），解锁只是让玩家看见。命格效果作用于该 NPC 作为伙伴/弟子/道侣/子嗣时（见 TEXT38A.mg[].fx）。
- 解锁「秘密」：每个秘密带一次性 `on` 效果串（首次解锁结算，走 `Game.apply`），并可能开放一个对话选项（`opt`）。
- 子嗣出生时按父母命格 30% 继承其一（hook `FAM37.birth` 后置包装，写 `kid.mg`）。

### 不支持/需新增的效果字段（代码目前没有）
| 字段 | 用途 | 状态 |
|---|---|---|
| `fx.compAtk/compHp` | 伙伴/道侣参战加成 | **代码不支持**，需在 battle 伙伴计算处包装 |
| `fx.disXp` | 记名弟子经验 ×(1+x) | **不支持**，需包 `FAM37.disYear` |
| `fx.kidLg` | 子嗣灵根上调概率 | **不支持**，需包 `FAM37.inheritLg` |
| `fx.debtRate` | 道侣对 `F.rate` 的影响 | 可用（fam37 `rate` 已存在） |
| `aff/karma/item/stone/flag` | 秘密一次性效果 | 可用（Game.apply 已有 case） |

## 6. Hooks 清单
1. `Talk` NPC 菜单 → 追加「查看详情」。
2. `UI.panel('pf38')`、`UI.titles.pf38='人物详情'`、`UI.p_pf38(b, npcId)`。
3. `Game.yearEnd` 包装：重置 `peek`；年末若 `taff − aff ≤ −30` 且为道侣/记名弟子 → 10% 触发「貌合神离」事件（TEXT38A.ev.drift）。
4. `FAM37.birth` 后置：子嗣命格继承。
5. 道具 use：`use:'peek'`（v40 窥心类）→ `PF38.reveal(id, key)`。
6. `Game.newLife`（轮回）：清空 `G.pf38.seen`，保留 nothing。
7. DevPanel 页签 `pf38`：一键全解锁 / 重置窥探次数。
