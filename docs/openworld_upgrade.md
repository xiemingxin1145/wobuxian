# 开放世界 / 混合战斗升级方案（v2.5+ 方向）

> 目标：在保持现有 2.5D 等距 + 人生模拟核心的前提下，往鬼谷八荒风格的开放感 + 即时/半即时战斗扩展，让游戏更爽、更有选择权重、减少“老套路”感。
> 当前基础：正式发布 v2.3.0；当前 `main` = `3baa83f`，仍是球体程序化模型、纯回合斗法、固定年度推进。实时战斗文件目前只是未接入的占位。

## 优先级与阶段

### 阶段 1：视觉与模型升级（最快见效）
- 从 Cube / Cylinder Extrude + Mirror + Loop Cut 做低模 Q 版人形底模（替代纯球体堆叠）。
- 本批明确做 3 个关键角色：主角男、主角女、剑仙；使用自建 Cube/Cylinder 挤出、Mirror 与 Loop Cut 形成的低模源模型，不采用 Quaternius/proto v2 替代本阶段路线。
- 渲染管线可复用现有 art/ 脚本，只改源模型。
- 目标：剪影更清晰，减少“鸡蛋”感。
- 预览为 Blender 独立场景，不接入 `www/`、精灵图集、正式地图或运行链；用贴近桃花村现有等距镜头/屏幕尺度的构图对比当前角色，检查身形比例、轮廓可读性，以及名牌/点击目标留白。清楚标注这是离线渲染对比，不是实机或运行中地图截图。
- 工具允许时，在独立预览中补充待机、移动和一个动作姿态；不为展示动画而接入游戏。

### 阶段 2：战斗混合化原型
- 地图探索保持等距自由走或走格子耗时间。
- 遭遇战 / 小怪战改为**即时或半即时**：玩家直接操控移动 + 普攻 + 技能 + 闪避，敌人放弹道/技能。
- 更轻量过渡：ATB（行动条到顶插队，可暂停选技能）。
- Boss 战和关键剧情战先保留回合制。
- 先做一个可玩的“遭遇战即时”原型（小地图或同地图切换）。

### 阶段 3：开放感与债务系统强化
- 随机奇遇链：地图上随机刷点，选择影响 NPC 态度、债务额度、下一世。
- NPC 简单动机：性格 + 当前目标 + 债务关系，赖账/帮人还债改变关系网。
- 功法/技能自由组合：灵根 + 武器类型产生不同弹道/效果。
- 时间颗粒度变细：从“一年一结算”改为月或行动力 + 时间流逝，移动/修炼/事件都耗时间。
- 债务贯穿一切：欠得多了有追兵、事件变负面、突破难度上升；还清或反杀天道才算真正“我不仙”。

## 不要一开始就做的
- 全 3D 无缝开放世界（引擎和管线都不适合）。
- 完全复制鬼谷八荒的弹幕 + 月结算大地图（可借鉴思路，但按现有 Canvas 架构适配）。

## 3.4 自由度层设计（鬼谷八荒式「世界自己在动」）— 2026-10-19，Grok Bot

> 已上线基础：3.4 无缝相邻地图（`seam34.js`，build-217）、大地图（`bigmap34.js`，build-219）。本节为第 3 步「世界模拟」，代码在 `www/js/life34.js`。

### 目标
玩家不推主线也有事发生：NPC 会换地方、记仇/记好，宗门之间会起冲突，冲突会**主动找上门**；每张地图一条可在任务栏追踪的奇遇链。

### 1. 年度世界模拟（`Life34.simYear`，挂在 `Game.yearEnd` 之后）
- **流动 NPC**（不动主线/任务 NPC）：首批 `luren`（路人甲）、新区 `b34_*` 6 人、`fisherm`、`shuoshu`。每年 35% 概率去 `seam34` 相邻图之一（只去玩家已解锁的图）。结果存 `G.life34.loc[id] = mapId`，通过包装 `NPCS[id].roam` 生效（原有 `roam` 优先）。
- **恩怨值** `G.life34.rel[id]`（-100..100，独立于好感 `G.aff`，不影响已有好感/道侣逻辑）：送礼/帮忙 +，抢怪/拒绝求助/赖账 −。≥40 记为「恩」，≤−40 记为「仇」。
- **宗门关系** `G.life34.sect[a+'|'+b]`（-100..100），`SECTS` 中两两随机漂移 ±(5..15)；≤−50 触发「宗门纠纷」事件；玩家所在宗门（`G.sect`）参与时更容易被找上。
- **世界大事记** `G.life34.log`（最近 20 条，年份+一句话），在「更多」面板的「江湖传闻」里看（第 2 期）。

### 2. 找上门的事件（`Life34.pending`）
- 年度模拟产出最多 1 个待触发事件，玩家下次**进入地图**时，对应 NPC 出现在玩家身边 2–3 格（真实实体，可点），头顶「！」；点他弹出 `UI.card` 选项。
- 类型：①仇人寻仇（打一场，用 `Game.fight` 现有怪物换皮/当前地图怪 +精英）②恩人报恩（灵石/物品）③宗门纠纷求援（帮 A 打 B 的弟子 → 宗门关系与贡献变化；不帮 → 关系小降）④流动 NPC 托付小事（送信到某图 = 奇遇链入口）。
- **自动任务/挂机安全**：这些卡的选项全部不进 `ux23.js` 的 `SAFE` 白名单；自动遇到就暂停（与现有规则一致）。不涉及道侣/借贷/拜师/结局。

### 3. 每图一条奇遇链（`Life34.CHAINS`，任务栏可追踪）
- 每条 3 步：`talk`（找某 NPC）→ `mark`/`kill`（某图交互点或打 N 只怪）→ `talk`（回报），奖励灵石/修为/恩怨。
- 以「任务」形式写入 `QUESTS`（id 前缀 `qc34_`，`giver` 为当图已有 NPC 或新区 NPC），复用现有任务栏/追踪寻路/`validate22`，不新建 UI。首批：桃花村（渡口船夫·过河欠条）、青云宗（守山弟子·后山禁地）、坊市（吆喝的小贩·假货风波）、秘境（迷路的寻宝人·第三个宝箱）、天外天（收费仙吏·踩云费）；其余图第 2 期。

### 4. 存档
- 新字段 `G.life34 = { v:1, loc:{}, rel:{}, sect:{}, log:[], pending:null, seen:{} }`，读档惰性补默认值；不改 `G.v`、不改章节 id。

### 5. 测试
- `test/life34_unit.py`（无头只读 + 开发者面板「过年」按钮点按）：连过 10 年，断言流动 NPC 至少换过一次图、`pending` 事件触发后进图能点到找上门 NPC、存档往返字段保留；奇遇链 3 步用真实触摸走完（可用开发者传送进图）。
- 门禁照旧（AGENTS.md §5）。

### 分期
- **期 1（本轮）**：#12 修复、地表打磨、邻图真实边条、流动 NPC + 恩怨值 + 找上门事件（寻仇/报恩/求援）+ 5 条奇遇链。
- 期 2：江湖传闻面板、宗门纠纷连锁（宗门大比/战争接 war29）、其余图奇遇链、NPC 之间的恩怨（NPC 互相结仇）。
