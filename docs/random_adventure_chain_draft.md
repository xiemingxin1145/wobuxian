# 随机奇遇链草稿（开放世界阶段 3）

> 目标：地图上随机刷点，玩家选择影响 NPC 态度、债务额度、下一世。
> 隔离：先做草稿，不接入正式任务栏，仅开发者入口或独立原型测试。

## 链结构（3 步）
1. **遇见**：随机 NPC（路人/流动者）向玩家求助（送信/还债/打怪）。
2. **选择**：
   - 帮忙：NPC 好感 +20，可能降债务。
   - 拒绝：NPC 态度 -15，可能记仇。
   - 赖账：债务 +10%，下一世承受部分。
3. **后果**：影响关系网，可触发追兵或报恩事件。

## 数据
- 随机刷点概率：进图后 15% 触发。
- 存档：用现有 G.flags / G.aff / G.life34.rel，不新增字段。
