# 随机奇遇链草稿（阶段 3 小闭环）

> 目标：提供可测试的“奇遇选择 → NPC 态度变化 → 债务后果”数据结构，不接入正式游戏运行链。
> 当前状态：草稿 + 独立原型已扩展多路径（贩子催债 + 云游散修 + 药农求助 + 黑市灵石），并有路径断言脚本。

## 数据结构示例

见 `www/prototypes/encounter_chain/index.html` 内 `CHAINS`。

核心字段：

- `debt`: 债务数值变化（正增负减）
- `aff`: NPC 好感度变化对象
- `time`: 耗时（月/行动力，草稿预留）
- `next`: 下一个奇遇 ID（可空）

## 已有链

1. **贩子催债** `debt_merchant_*`：帮摆摊 / 推说下回 / 赖账 → 追兵风声
2. **云游散修** `wander_cultivator_*`：借灵石 / 婉拒 / 切磋换消息
3. **药农求助** `herb_farmer_*`：帮驱虫 / 自己采 / 无视
4. **黑市灵石** `black_market_*`：成交欠人情 / 压价 / 拒绝

## 验证

仓库根目录执行：

```bash
python3 -B test/encounter_chain_verify.py
```
